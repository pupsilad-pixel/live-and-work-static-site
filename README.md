# Живи и работай в Татарстане

Статический адаптивный лендинг-каталог на чистых HTML, CSS и JavaScript.

## Запуск

Откройте проект через любой локальный HTTP-сервер. Например, из папки проекта:

```powershell
python -m http.server 8080
```

После этого сайт доступен по адресу `http://localhost:8080`.

## Данные

Демонстрационные вакансии, районы, меры поддержки, истории и FAQ находятся в `js/data.js`. Формы работают в демонстрационном режиме и не отправляют персональные данные на сервер.

## Следующий этап

Перед публикацией необходимо заменить демонстрационные контакты и тексты, подключить утверждённые фотографии, юридические документы и серверную обработку заявок.
