# Живи и работай в Татарстане

Статический адаптивный лендинг-каталог на чистых HTML, CSS и JavaScript.

## Запуск

Откройте проект через любой локальный HTTP-сервер. Например, из папки проекта:

```powershell
python -m http.server 8080
```

После этого сайт доступен по адресу `http://localhost:8080`.

## Данные

Демонстрационные вакансии, районы, меры поддержки, истории и FAQ находятся в `js/data.js`. Показатели на главной странице рассчитываются из этих данных, поэтому не расходятся с наполнением каталога. Формы работают в демонстрационном режиме и не отправляют персональные данные на сервер.

В `assets/images/placeholders/` находятся три сгенерированные AI-заглушки для паспортов территорий. Они не являются документальными фотографиями конкретных городов и должны быть заменены утверждёнными материалами перед официальной публикацией.

## Следующий этап

Перед публикацией необходимо заменить демонстрационные контакты и тексты, подключить утверждённые фотографии, юридические документы и серверную обработку заявок.
